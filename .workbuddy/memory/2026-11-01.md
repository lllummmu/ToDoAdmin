- 关键环境事实：
  - Tomcat 8.5.50 端口 8081；项目文档根 web/ 无法直接作 docBase（Tomcat 忽略 appBase 内 docBase），方案：scripts/deploy.bat 编译并镜像 web/ → D:\apache-tomcat-8.5.16\deploy\TodoApp，上下文描述符 conf/Catalina/localhost/TodoApp.xml 指向它。
  - 本机 shell 有 HTTP 代理：curl 需加 --noproxy '*' 访问 localhost。
  - 后台进程（Tomcat/Vite）必须用 run_in_background 启动，否则命令结束进程被回收。
  - 数据库 todo_app（MySQL84 服务），连接串在 DBUtil.java；旧表原为 GBK，已转 utf8mb4；serverTimezone 改为 Asia/Shanghai。
  - Vite 代理需改写 JSESSIONID 的 Path（/TodoApp → /），否则 5173 下会话失效。
  - JDBC 坑：setObject(参, null) 写 MySQL 成 0/1970 等默认值，必须 setNull；getObject(col, Integer.class) 读 NULL 返回 0，用 getInt + wasNull。
